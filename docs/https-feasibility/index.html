GaggiGo HTTPS Feasibility Evidence Test

Evidence tool only. This page does not modify GaggiGo, GaggiMate, IndexedDB, settings, profiles, shots, or machine state. It tests browser behaviour for HTTPS app-shell feasibility against a local GaggiMate HTTP/WebSocket endpoint.

  2. Service worker availability
